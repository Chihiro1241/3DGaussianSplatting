# 3DGS 実験記録

## 目的

`output/runXXX*` に保存された学習条件、結果、変更理由および考察を、後から再現・比較できる形で管理する台帳である。実験出力そのものは変更せず、各runの記録は対応するMarkdownに集約する。

## 運用ルール

- 一つのrunでは可能な限り検証対象を限定する。
- 実験条件を変更した理由を記録する。
- 実行時のGit branch、commit、working treeの状態およびpush状況を必ず記録する。
- 実験結果だけでなく考察と次に試す実験を記録する。
- 不明な値を推測して埋めず、`不明`または`要追記`とする。
- 機械的に取得した値と、人間が記述する目的・変更理由・考察を区別する。
- 新規runは [template.md](template.md) をコピーし、実行開始時と終了時に更新する。
- `output/` は実験成果物の保存先であり、本台帳の整理を理由に移動・rename・変更しない。

## ADCの区分

- run001〜run005は保存configの`features.adaptive_density_control: false`を根拠にADC導入前のfixed-Gaussian実験として区別できる。
- run006〜run014は保存configの同フラグが`true`であり、ADCを使用した実験である。
- Git履歴では`dbd35cd`（2026-08-20）がADC学習統合commitである。ただし、実行時commitが成果物に保存されていないため、個々のrunとの対応は確定していない。
- run006〜run008はディレクトリ名の`preflight`を根拠にADC開発中の事前検証とする。
- run014はディレクトリ名ではbaselineとされるが、完了後の評価と考察が未記録である。ADC baselineとしての確定は要追記である。
